# Bird Catalogue — Cloud Systems Exercise

A school exercise built around a static HTML, CSS and JavaScript bird catalogue. The repository includes bird data and images, plus client code for calling an API and handling authentication callbacks.

Serve the repository root with a local HTTP server, for example `python3 -m http.server 8000`, then open http://localhost:8000. The static files can be served locally. API and sign-in features depend on the external services referenced by `scripts/config.js`.
